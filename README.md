# Bakhoor — perfumería árabe (Caracas y Punto Fijo)

Landing page y documentación de marca del negocio de perfumes árabes (Afnan, Armaf, Lattafa, Rasasi y más).

- `index.html` — landing page estática (sin backend, CTA por WhatsApp). Lista para desplegar en Vercel tal cual.
- `assets/bakhoor_logo.png` — logo de marca.
- `docs/branding/identidad_marca.md` — paleta, tipografía, tono, reglas de marca.
- `docs/catalogo/estrategia_precios.md` — catálogo e inventario con precios sugeridos.
- `docs/plan-contenido/guia_contenido.md` — pilares de contenido y calendario para Facebook/Instagram.
- `docs/seo_y_arquitectura.md` — qué es (y qué no es) técnicamente esta landing.
- `docs/plan-automatizacion.md` — contexto para cualquier automatización que siga iterando este repo: guardrails, stack objetivo (GitHub/Vercel/Supabase), y qué necesita confirmación humana antes de ejecutarse.

**Antes de tocar nada acá, leer `docs/plan-automatizacion.md`.**
